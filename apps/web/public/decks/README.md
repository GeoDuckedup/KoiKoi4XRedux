# Technical runtime deck fixtures

`technical-sunrise` and `technical-moonlight` are deterministic generated Phase 2B fixtures. They
exist to validate complete browser manifests, persistent CardViews, texture loading, local package
switching, responsive readability, and GitHub Pages asset routing.

They are **not finished card art**, do not replace `decks/new-primary-deck/`, and carry no visual-art
approval. Regenerate them with `npm run generate:technical-runtime-decks`; verify checked-in output
with `npm run validate:technical-runtime-decks`.
