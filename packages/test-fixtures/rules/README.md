# Rule fixtures

Phase 0C binds the named specifications in `docs/TEST_VECTORS.md` to canonical CardIds. Phase 1A
makes DEAL-001 through DEAL-012 executable against authored 48-card deck orders. Phase 1B adds
executable CAP-000 through CAP-DRAW-003 turns with exact hands, fields, ordered draws, commands,
checkpoints, captures, and events. Later Phase 1 subphases add yaku, decision, round, match,
projection, and replay fixtures.
